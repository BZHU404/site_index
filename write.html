· 本页说明 ·

一个给这个博客用的纯文本编辑器。内容不会发送到任何地方，文章会留在这个浏览器里，直到你导出。

快捷键：
Ctrl / ⌘ + S — 保存

· MARKDOWN 语法 ·

  • **bold**
  • *italic*
  • ## heading
  • - list item
  • [text](url)
  • > quote

没有云，也没有找不到的草稿文件夹。只有一个文本框。

首页 / 博客 / 写作台

写作台

写一篇文章，预览它，然后保存在这个浏览器里。觉得可以了，再导出 posts.js，替换站点文件夹里的那个文件。

仅本机 — 文章先保存在这台电脑的浏览器里，不会自动出现在别人的屏幕上。导出 posts.js 并替换站点文件，才算真正发布。

撰写

a–z、0–9、连字符；保存后锁定。

英文逗号分隔，最多八个。

显示在博客列表里；留空会自动生成。

简单 Markdown；空一行开始新段落。

本机已保存

发布

导出会替换 posts.js 里的所有文章。操作前先备份旧文件。

导入已有的 posts.js（或 JSON 列表），在这里继续编辑。

使用说明

  1. 先写，再保存。红色的 本地 标记表示文章只存在这个浏览器里。
  2. 点击 导出 posts.js，下载更新后的文件。
  3. 用新文件替换站点文件夹里的 posts.js，再上传整个文件夹。这才算发布。

预览

开始输入，文章会显示在这里。
